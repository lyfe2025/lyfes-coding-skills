# 模板设计

新建主页、个人品牌页、作品集或平台模板时使用本指南。

## 模板简报

编码前先输出并确认以下内容：

```markdown
## 模板定位

- 模板名称：
- 目标用户：
- 访客主要任务：
- 内容优先级：
- 核心行动：
- 主要设备：
- 视觉方向：
- 视觉记忆点：
- 技术与内容约束：
- 与现有模板的差异：
```

## 从内容叙事选择结构

不要默认使用 `Hero > Features > Testimonials > CTA`。根据访客决策过程选择结构：

- **Personal homepage**：身份定位 → 代表成果 → 经历或观点 → 联系方式
- **Portfolio**：代表项目优先 → 项目方法与角色 → 能力证明 → 合作入口
- **Creator**：内容主张 → 最新或精选内容 → 订阅/社交渠道 → 商务合作
- **Consultant**：问题与结果 → 方法和服务 → 案例证据 → 咨询入口
- **Developer**：当前工作 → 代表项目 → 技术文章或开源贡献 → 联系方式
- **Editorial**：主题或观点 → 内容索引 → 专题/档案 → 作者信息

这些是叙事起点，不是固定 section 模板。删除不能帮助访客决策的区块。

## 差异化门槛

新模板至少在以下三个维度与现有模板形成真实差异：

- 信息架构
- 内容优先级
- 网格与构图
- 导航模式
- 字体关系
- 图像比例
- 项目或内容呈现方式
- 页面节奏
- 有意义的交互方式

换颜色、渐变、圆角、阴影或区块顺序，不足以构成新模板。

## 内容与组件边界

- 首屏回答“是谁、提供什么、为什么继续看”，不要求每次都有大标题和双 CTA。
- 只保留一个 Primary action；Secondary action 必须明显降级。
- 卡片用于独立、重复、可操作或需要边界的内容，不要把每个 section 卡片化。
- 图片必须承担人物识别、案例证据、过程说明或氛围建立中的一种角色。
- 没有图片时仍应保持成立，不用空占位破坏层级。
- 移动端重新安排信息优先级，不只是缩小桌面布局。

## 真实内容测试矩阵

实现完成后至少检查：

- 中文长标题、英文长单词与混合语言
- 一行和多行简介
- 0、1、3、10 个项目或内容条目
- 横图、竖图、方图和缺图
- 某些可选区块完全为空
- 社交链接少量与大量
- 375px 移动端和 1440px 桌面端
- 触控访问、键盘访问与 Reduced Motion

模板的默认内容应展示真实使用方式，而不是只为截图准备的理想短文案。

## 设计交付

交付模板时同时说明：

- 目标用户与核心转化
- 结构选择理由
- 三项以上差异化维度
- 内容缺失与极端长度如何降级
- 桌面和移动端的主要布局差异
- 使用了哪些专项 Skill，以及为什么需要
